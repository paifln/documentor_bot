# Documentor — материалы к демонстрации

Готовая речь: [docs/DEFENSE_SPEECH.md](docs/DEFENSE_SPEECH.md).

Documentor сочетает программные проверки OOXML и вероятностный AI-анализ текста. Поддерживает четыре типа работ и три языка интерфейса. Программные проверки воспроизводимы, но зависят от полноты поддержки OOXML: стопроцентная проверка всех документов Word не обещается.

## Что показать

1. /start, выбор языка и типа работы.
2. Загрузка DOCX; подпись можно использовать как тему.
3. Отдельный worker получает задачу через Redis. В БД уже сохранены задание и снимок требований.
4. Пользователь получает замечания, оценку по проверенным категориям и PDF.
5. В mock-режиме показать «Не проверено» для AI-категорий. Mock не доказывает работу реальной модели.
6. Тесты наследования стилей, интервалов, изоляции владельцев, квот, отмены worker, доставки и миграций.

Файлы demo иллюстрируют оформление, но не являются полным эталоном всех правил, включая минимальное число слов.

## Технические вопросы

- БД: SQLite локально, PostgreSQL в Docker; схема через Alembic.
- Redis переносит ID задач. Источник истины — SQL, поэтому принятые задания восстанавливаются после сбоя Redis.
- Ошибка Telegram не отменяет анализ: доставка повторяется отдельно, без повторного AI.
- Максимум всегда 100. При неполном AI итог нормируется по доступным категориям и явно обозначается предварительным; показывается охват текста. Непроверенные категории не получают баллы.
- Старые оценки не меняются после обновления YAML: сохраняются снимки требований и результата.
- Антиплагиата нет; библиография не проверяется на существование или достоверность источников.
- Число страниц оценивается по тексту, без движка вёрстки Word.
- Документы защищены проверкой владельца, лимитами скачивания/распаковки, случайными именами и сроками хранения.
